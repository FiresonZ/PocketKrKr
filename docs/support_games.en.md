# Supported Games

> This page lists KiriKiri2 games that have been verified to run or launch on PocketKrKr.
> Compatibility is updated based on actual test results; see [Game Compatibility](dev/compatibility.md) for details.

## Confirmed Support

| Game | Release date | Notes |
| ---- | -------- | ---- |
| 天神乱漫 LUCKY or UNLUCKY!? | 2009-05-29 | Verified to run |

## How to Contribute

- Run the game on a real device and confirm that it launches, then add it to the table above (game name, release date, and notes).
- For compatibility issues (black screen, crash, script errors, etc.), first check [To-do / Known Issues](dev/todo.md) to see whether they are already known,
  then record the issue according to the process in [Game Compatibility](dev/compatibility.md).
