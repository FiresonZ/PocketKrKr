# API 契约

## 用途

记录稳定的 C ABI、Dart FFI、TJS 原生方法、插件方法和跨模块参数契约。这里只写调用方、参数、返回值、错误语义、生命周期和版本约束。

## 当前状态

本页是分类入口。已有契约仍分散在 [关键引用](key-references.md)、源码头文件和插件实现中，后续按公共接口变更逐项迁入。

## 写入条件

只有当接口被跨模块调用、被脚本/插件依赖、或需要版本兼容时才建立条目。私有函数和临时诊断参数不写入本页。
