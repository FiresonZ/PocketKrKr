# Release Notes

## Purpose

Record user-visible feature, compatibility, build, platform, and migration impact by release. Do not write development trial-and-error, internal commit IDs, or temporary logs here.

## Current Status

This page is the entry point for future release changes. The repository has no stable release record yet, so no fictional version is listed.

## Writing Conditions

Add an entry only when the release scope, user impact, and verification state are clear. Each change should state whether reinstalling, save migration, or configuration changes are required.
