# Test Fixtures

## Purpose

Record reproducible game, script, resource, font, plugin, and rendering fixtures. Each fixture must let another developer prepare the input again and judge the result.

## Current Status

This page is a category entry point. Current compatibility requirements are in [Compatibility Testing](compatibility.en.md). Font and rendering verification still relies mainly on target-platform regression; register cases here when they can run independently of a device.

## When to Add an Entry

Register only stable, distributable, or generatable inputs. Do not commit personal game paths, user resources, complete logs, private device data, or unauthorized commercial assets.
