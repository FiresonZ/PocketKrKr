# 通用参考

本目录只保存根据公开行为和本项目验证结果整理的抽象设计参考，不保存外部仓库源码、逐行改写、项目专有名称或可识别的实现结构。

## 内容

- [文字基线契约](text-baseline-contract.md)：记录位图字体、运行时字体和裁剪之间的通用度量关系。
- [动画同步契约](animation-sync-contract.md)：记录时间线、跳过、完成通知和实例隔离的通用行为。

## 写入规则

- 只写协议、数据关系、伪代码、验收条件和本项目的独立结论。
- 不复制外部仓库的源码、注释、测试名称、类层级或项目专用标识。
- 外部资料只保留在 [兼容性与参考资料](../krkrz-compat.md) 的统一入口。
- 参考内容不能替代本项目代码、测试和目标平台验证。
- 已被实现并验证的内容应迁移到对应的架构、接口、兼容性或测试文档；本目录不作为长期待办清单。
