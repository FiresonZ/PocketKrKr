# General References

This directory stores abstract design references derived from public behavior and independently verified PocketKrKr results. It does not store external source code, line-by-line rewrites, project-specific names, or recognizable implementation structures.

## Contents

- [Text Baseline Contract](text-baseline-contract.en.md): General metric relationships between bitmap fonts, runtime fonts, and clipping.
- [Animation Sync Contract](animation-sync-contract.en.md): General behavior for timelines, skipping, completion signals, and instance isolation.

## Writing Rules

- Record only protocols, data relationships, pseudocode, acceptance conditions, and independent conclusions from this project.
- Do not copy external source code, comments, test names, class hierarchies, or project-specific identifiers.
- Keep external references only in the unified [compatibility and references](../krkrz-compat.en.md) entry.
- Reference material does not replace this project's code, tests, or target-platform verification.
- Once a reference is implemented and verified, move it to the relevant architecture, interface, compatibility, or testing document; this directory is not a permanent todo list.
