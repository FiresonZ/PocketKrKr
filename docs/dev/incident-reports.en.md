# Incident Reports

## Purpose

Record confirmed issues with reproduction conditions, evidence, root-cause boundary, fix, verification, and residual risk. This is not a live-log repository or a todo list.

## Current Status

This page is a category entry point. Create an entry after the issue has stable reproduction conditions or sufficient evidence; keep unconfirmed hypotheses in the active workflow or todo list.

## When to Add an Entry

Create an entry only when the issue has stable reproduction conditions or enough evidence. Remove personal paths, complete user text, device-private data, secrets, and unrelated logs.
