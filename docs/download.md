发布物托管在 GitHub **Releases**。

## Android

直接安装 APK（无需签名）。

- **当前版本**：[PocketKrKr Android v0.0.1](https://github.com/FiresonZ/PocketKrKr/releases/tag/android-v0.0.1)
- **直接下载**：[PocketKrKr-Android-release.apk](https://github.com/FiresonZ/PocketKrKr/releases/download/android-v0.0.1/PocketKrKr-Android-release.apk)（约 108 MB）
- **系统要求**：Android 7.0 / API 24+　·　arm64-v8a　·　需支持 Vulkan 的 GPU
- **安装方式**：下载 APK 后允许「安装未知来源应用」即可安装；更新时直接覆盖安装旧包。
