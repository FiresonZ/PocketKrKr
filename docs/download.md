# 下载

PocketKrKr 的开发构建由 [GitHub Actions](https://github.com/FiresonZ/PocketKrKr/actions) 自动打包，
发布物托管在 GitHub **Releases**。当前最新版本为 **v0.0.1**（iOS + Android，2026-09-07 发布）。

> **[前往最新 Release 页面](https://github.com/FiresonZ/PocketKrKr/releases/latest)**　　
> **[查看全部 Release](https://github.com/FiresonZ/PocketKrKr/releases)**

## Android

直接安装 APK（无需签名）。

- **最新版本**：[PocketKrKr Android v0.0.1](https://github.com/FiresonZ/PocketKrKr/releases/tag/android-v0.0.1)
- **直接下载**：[PocketKrKr-Android-release.apk](https://github.com/FiresonZ/PocketKrKr/releases/download/android-v0.0.1/PocketKrKr-Android-release.apk)（约 108 MB）
- **系统要求**：Android 7.0 / API 24+　·　arm64-v8a　·　需支持 Vulkan 的 GPU
- **安装方式**：下载 APK 后允许「安装未知来源应用」即可；更新时直接覆盖安装旧包。

## iOS

未签名 `.ipa`，需用你自己的 Apple 开发者证书/工具侧载签名后安装。

- **最新版本**：[PocketKrKr iOS v0.0.1](https://github.com/FiresonZ/PocketKrKr/releases/tag/ios-v0.0.1)
- **直接下载**：[PocketKrKr-iOS-release-nosign.ipa](https://github.com/FiresonZ/PocketKrKr/releases/download/ios-v0.0.1/PocketKrKr-iOS-release-nosign.ipa)（约 29 MB）
- **系统要求**：iOS / iPadOS 15.0+　·　arm64
- **安装方式**：本包为**未签名** `.ipa`，需自行签名后侧载；可用
  [AltStore](https://altstore.io) / Sideloadly（配合 Apple ID 与「信任开发者」）。
